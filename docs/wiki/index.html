About This Project

This project connects 3 boards (theSpeaker, environment, motor_n_mike) using 7 communication protocols (TCP, SPI, I2C, BLUETOOTH). It is built with ESP-IDF and includes 3 peripheral components for sensing, actuation, and communication.

Quick Start

  1. Review Hardware: Check the Bill of Materials and acquire all components
  2. Wire Components: Follow the wiring diagram to connect all boards and sensors
  3. Install ESP-IDF: Set up the Espressif IoT Development Framework 
    # Follow: https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/
  4. Build & Flash: Compile firmware and flash to each board (see Build Instructions)
  5. Verify: Monitor serial output to confirm boards are communicating
