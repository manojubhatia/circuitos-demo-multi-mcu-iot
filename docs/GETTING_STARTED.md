# Getting Started

This guide walks you through building, flashing, and running the complete system.

## Prerequisites

| Tool | Version | Installation |
|------|---------|-------------|
| ESP-IDF | v5.1+ | [docs.espressif.com](https://docs.espressif.com/projects/esp-idf/en/latest/esp32/get-started/) |
| Python | 3.10+ | [python.org](https://www.python.org/downloads/) |
| Node.js | 18+ | [nodejs.org](https://nodejs.org/) |
| Git | 2.x+ | [git-scm.com](https://git-scm.com/) |

## Step 1: Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
```

## Step 2: Build & Flash Firmware

Make sure ESP-IDF is sourced in your terminal:

```bash
. $HOME/esp/esp-idf/export.sh
```

Then build and flash each board:

### theSpeaker (ESP32)

**Target:** `esp32` | **Role:** Master

```bash
cd device_theSpeaker
idf.py set-target esp32
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
```

> 💡 If you have multiple boards connected, specify the port explicitly:
> `idf.py -p /dev/ttyUSB1 flash monitor`

### environment (ESP32-C3)

**Target:** `esp32c3` | **Role:** Slave

```bash
cd device_environment
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
```

> 💡 If you have multiple boards connected, specify the port explicitly:
> `idf.py -p /dev/ttyUSB1 flash monitor`

### motor_n_mike (ESP32C3)

**Target:** `esp32c3` | **Role:** Slave

```bash
cd device_motor_n_mike
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
```

> 💡 If you have multiple boards connected, specify the port explicitly:
> `idf.py -p /dev/ttyUSB1 flash monitor`


## Step 3: Run the Backend

```bash
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

The backend API starts on **http://localhost:8000**. You can verify it's running:

```bash
curl http://localhost:8000/health
```

## Step 4: Run the Frontend Dashboard

```bash
cd frontend
npm install
npm run dev
```

The dashboard opens at **http://localhost:3000** with real-time charts and device status.

## Step 5: Using Scripts (Shortcut)

For convenience, one-click scripts are provided:

```bash
./scripts/start_backend.sh     # Start backend in virtual environment
./scripts/start_frontend.sh    # Start frontend dev server
./scripts/build_device.sh      # Build all firmware targets
./scripts/flash_device.sh      # Flash to connected board
```

## Troubleshooting

| Issue | Solution |
|-------|----------|
| `idf.py: command not found` | Source ESP-IDF: `. $HOME/esp/esp-idf/export.sh` |
| Port permission denied | Add user to dialout: `sudo usermod -a -G dialout $USER` |
| Backend can't find modules | Activate venv: `source venv/bin/activate` |
| Frontend build fails | Delete `node_modules` and run `npm install` again |
| Board not detected | Check USB cable (must be data cable, not charge-only) |
