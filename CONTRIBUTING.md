## How to Contribute

### Report Issues
If you find a bug in the generated code, please open an issue describing:
- What you expected to happen
- What actually happened
- Your hardware setup (board, components, connections)

### Suggest Improvements
If you'd like to see improvements in the generated output (better driver implementations,
additional protocols, new components), please visit [circuitos.dev](https://circuitos.dev)
and submit feedback.

### Architecture
Before making changes, please read [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) to understand
the 4-layer architecture. Any modifications should maintain the PAL/OSAL/Middleware/Application
separation.
